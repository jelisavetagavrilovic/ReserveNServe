# User Guide

ReserveNServe is a restaurant reservation and food pre-ordering platform. This guide provides a short overview of the main actions available to users of the system.

## User Roles

### User

- register and sign in
- confirm their email address
- browse restaurants
- view restaurant details and menus
- search for available reservation slots
- create a reservation
- pre-order food and drinks
- complete online payment when required
- view and manage reservations
- cancel a reservation
- receive confirmation, cancellation, and refund emails


## Typical Reservation Flow

1. Sign in or create an account.
2. Browse available restaurants.
3. Open a restaurant to view its details and menu.
4. Choose a date and number of guests.
5. Select an available reservation slot, and table.
6. Optionally add food or drinks to the pre-order.
7. Confirm the reservation.
8. Complete the payment if payment is required.
9. Receive a confirmation email.

## Managing Reservations

Users can review their reservations from the application and, where allowed by the reservation rules, cancel an existing reservation.

If a paid reservation is eligible for a refund, the refund is processed through the payment system and the user receives the corresponding email notification.

## Account Operations

ReserveNServe supports common account operations such as:

- registration
- login
- email confirmation
- password reset
- logout

## Email Notifications

The system sends transactional emails for important account and reservation events, including:

- account/email confirmation
- password reset
- restaurant-owner request approval
- reservation confirmation
- reservation cancellation
- refund confirmation

During local development, outgoing emails can be inspected through Mailpit.
